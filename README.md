# sleek_ink creatives

Website and brand system for sleek_ink creatives, a design and software studio.

- `index.html` — the home page
- `brand/` — the brand guidelines
- `assets/brand/` — logo files (SVG)
- `assets/fonts/` — Bricolage Grotesque, Instrument Serif and DM Mono (all SIL Open Font License)

Plain HTML, CSS and a little JavaScript. No build step: open `index.html`, or serve the folder with any static host.
